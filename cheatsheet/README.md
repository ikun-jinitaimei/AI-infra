# Cheatsheet：给优化 Agent 的算法说明

## 问题与起点

在长度约束内提供优化指导，保留算法语义和适用边界。

## 假设与修改

整理 CSA/位切片算法与空掩码、计数位宽、初始化等必要约束；控制文本长度。

## 验证与限制

最终 397 tokens，格式验证通过；最后边界修改没有重跑 Agent，不能声称最终端到端性能已验证。

## 代码与复现

本目录保留：SKILL.md、submission.yaml。官方基线与接口需按[复现说明](../docs/reproduction.md)获取。详细版本演进见[实验记录](../docs/optimization-history.md)，数值与证据见[结果说明](../docs/results.md)。

## 学习重点

# Accelerate：查询批处理与向量数学

## 问题与起点

官方核场响应计算包含查询与中心之间的距离、点积和数学函数。起点与正式计时接口由官方框架提供。

## 假设与修改

从代码与 A/B 实验推测重复读中心数据、标量数学调用和范围判断存在成本。采用 16 查询分块、NEON 双精度累积、向量多项式与输入范围上界外提；扫描仍计入正式调用。范数分解在 D16 补充实验较慢，保留直接距离路径。

## 验证与限制

公开 large-b 三新进程 1178.474888 / 1055.040193 / 1091.169983 ms，取最大值。34 个压力用例及官方 sample 通过。没有同口径全套官方 baseline 的最终重复样本，不宣称总题加速比。

## 代码与复现

本目录保留：src/solver.py、env.sh。官方基线与接口需按[复现说明](../../docs/reproduction.md)获取。详细版本演进见[实验记录](../../docs/optimization-history.md)，数值与证据见[结果说明](../../docs/results.md)。

## 学习重点

向量化需要同时考虑数据复用、数学精度、边界与输入转换成本。

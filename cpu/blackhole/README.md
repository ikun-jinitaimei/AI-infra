# Blackhole：插值、共享内存与球谐收缩

## 问题与起点

每轮更新场数据，再在球面采样插值并计算球谐输出。

## 假设与修改

缓存几何模板而非场值答案，MPI 共享窗口直接读取当轮数据，树形同步与归约；z 行/系数复用、紧凑索引、NEON、先 Fourier 后球谐收缩。保持全部迭代、探测器、采样点和计时范围。

## 验证与限制

small/medium/large/huge 分别 0.081714734 / 8.150199762 / 13.203233896 / 26.990718491 s，四个完整用例通过原容差；本地规则 100/100。没有把不同规模或节点的历史短测试作为严格 baseline。

## 学习重点

复用不变量、减少数据移动与通信次数，以及计算重组，往往比仅提高算术吞吐更重要。

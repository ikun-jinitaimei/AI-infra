# Mahjx：避免重复工作与并行枚举

## 问题与起点

在线处理对局，枚举听牌与候选概率并完成决策分析。

## 假设与修改

Sparsemax 排除数学上零权重项，完整状态缓存，根分支并行；重复递归后缀用整数重数表示，紧凑牌计数、内联容器与概率扫描融合。重数保留概率质量，但浮点累加次序变化必须验证。

## 验证与限制

两个完整公开对局通过官方 interactor/checker：189.940524283 s 和 224.589909114 s，共 414.530433397 s。隐藏对局未测试。

## 代码与复现

本目录保留：optimization.patch（已测版本；最后未测追加包不包含在此补丁）。官方基线与接口需按[复现说明](../../docs/reproduction.md)获取。详细版本演进见[实验记录](../../docs/optimization-history.md)，数值与证据见[结果说明](../../docs/results.md)。

## 学习重点

先消除冗余计算和对象成本，再讨论线程扩展；在线协议与数值容差也是优化边界。

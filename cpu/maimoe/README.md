# MaiMoe：解析到渲染的流水线优化

## 问题与起点

官方程序解析谱面、演化状态、计算摘要并输出固定大小渲染数据。性能起点是已修改过封装的接手版本。

## 假设与修改

减少中间对象和字符串格式化，紧凑事件表示、同 tick 局部排序、前缀复用、直接输出，使用 ARM SHA 和 NEON，调整 worker/batch。保留语义错误处理与必需摘要。

## 验证与限制

最终四组均值 72.263995 / 167.357696 / 168.307121 / 616.736593 ms；1 warmup + 3 repeats；本地估分 99.80382035。最大样例比接手版约 6.01×；2603 个差分输入覆盖有效与拒绝路径。

## 代码与复现

本目录保留：solution/Kernel.cpp、solution/KstroParam.toml。官方基线与接口需按[复现说明](../../docs/reproduction.md)获取。详细版本演进见[实验记录](../../docs/optimization-history.md)，数值与证据见[结果说明](../../docs/results.md)。

## 学习重点

系统优化不只在数学内核，解析、分配、复制、格式化和流水线配置都可能主导耗时。

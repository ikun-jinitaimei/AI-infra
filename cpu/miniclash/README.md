# Miniclash：SIMD 搜索与受控实验

## 问题与起点

基于官方提供的 MD5 碰撞搜索框架与第三方整数候选内核。

## 假设与修改

对候选循环做 16 路 SIMD 批处理，保留筛选顺序和标量验证，端到端保持竞争调度。PGO、固定重启、事件调度与 I/O 修改没有稳定收益；掩码归约的微基准收益没有转化为明确端到端收益。

## 验证与限制

两轮 32/64/128/256 任务分别 4.34/7.56/12.89/29.21 s 与 4.30/7.49/12.02/26.48 s，官方检查通过；随机任务估分不等于 OJ 得分。

## 代码与复现

本目录保留：source_code/（保留第三方 LICENSE.txt）。官方基线与接口需按[复现说明](../../docs/reproduction.md)获取。详细版本演进见[实验记录](../../docs/optimization-history.md)，数值与证据见[结果说明](../../docs/results.md)。

## 学习重点

控制随机种子、交替测试与多轮端到端验证，比只挑最快一次更有说服力。

# 发布范围与来源

本仓库由本地开发目录筛选导出，公开目录本身不包含原仓库的 Git 历史。只上传本目录，不能对整个开发工作区直接 `git add .`。

| 类别 | 处理 |
|---|---|
| 官方 baseline / 原始赛题 | 提供上游链接、固定提交和复现步骤，不复制完整仓库 |
| 优化源码 | 按案例保存允许修改的源码；Blackhole/Mahjx 使用已测差分补丁 |
| Benchmark | 导出去除运维标识的结果字段、版本指标和来源摘要 |
| 失败实验 | 保留解释与关键数据；完整快照仍在本地档案 |
| 未测候选 | 独立目录和状态说明，不冒充最终实测结果 |
| 答案、账号操作、运维日志 | 不发布 |
| 测试数据、模型、镜像、编译产物 | 不发布，通过官方渠道获取所需资源 |
| 网页抓取与传输临时包 | 不发布；本地清理采用可恢复归档 |

文本扫描覆盖公开文件的凭据格式、私人账号/路径、SSH 连接、私网地址及大文件；摘要和相对 Markdown 链接另行核对。这是静态检查，不是不存在任何敏感内容的数学保证，也不代替对赛题许可和数据使用范围的人工判断。没有把扫描命中的原始内容写入公开报告。

官方来源及原有许可保留于 LICENSE / THIRD_PARTY_NOTICES.md。未为上游或第三方代码另行宣称新的授权。详细本地文件清单、疑似运维信息位置及清理清单只留在开发目录，不上传。
